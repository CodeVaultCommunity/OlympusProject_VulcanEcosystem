# Integration guides

[Português](README.pt-br.md) · [Minerva → Vulcan](minerva/README.md)

This directory explains how to interpret another model and manually realize it in Vulcan. It contains documentation only: no translator, code generator, model reader, adapter library or migration engine. `vendor/` normally holds copied third-party runtime/tool code; that arrangement has been removed. Immutable source documents remain in `verification/sources/` for provenance, separately from tooling.
