# Modelo para adoção

[English](README.md)

Use o [ecossistema minimal](../examples/minimal/README.pt-br.md) como ponto de partida executável. Este roteiro é um modelo documental, sem gerador ou segundo exemplo executável incompleto.

1. Identificar edições-fonte, IDs dos casos, decisões aprovadas/abertas e hashes.
2. Declarar aplicativos, linguagem/perfil, operações públicas, colaboradores concretos e vida útil dos recursos.
3. Criar `apps/` e registro/entrada explícitos na raiz; escolher modos padrão e opcionais.
4. Adotar `docs/L1_AtlasSpecifications`, `L2_MinervaBlueprints`, `L3_Vulcan` e `Shared` quando aplicáveis.
5. Implementar contratos/canais selecionados; preservar permissão, validação, falhas e persistência.
6. Mapear cenários/apoios ADVS para testes executáveis e observações por arquivo para L2.
7. Executar verificações e registrar ambiente/resultados/limites reais. Revisar mudanças antes de atualizar hashes.
