# Contributing

Select the target edition and read AGENTS.md. Maintain model rules, representation, examples and tools together. Keep English normative text and Portuguese translation aligned. Add a focused regression test when changing validation or execution behavior; report the environment and actual outcomes. Update the requirements mapping for changes in scope. Follow docs/releasing.md after all sources, resources and evidence are final. Published edition snapshots are immutable; use a new version for incompatible contracts.
