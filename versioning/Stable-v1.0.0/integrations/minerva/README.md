# Minerva integration

Vulcan Stable-v1.0.0 consumes only `minerva-project/1.0.0` projects whose
semantic authority is `distributed_markdown_modules`. It reads every listed
Markdown module and its controlled `atlas-source-json` and
`minerva-design-json` records.

The Minerva target is normative for the file path, symbol, and designed public
methods. Vulcan adds code, dependency wiring, runtime support, and evidence;
it may not silently discard Atlas semantics or substitute a central appendix.

Concrete-tool code must implement the abstract-tool lineage named by Minerva.
Interaction code may be called Boundary. Test scenarios and instrumentation
must use observation-point terminology instead.
