# Guias de integração

[English](README.md) · [Minerva → Vulcan](minerva/README.pt-br.md)

Esta pasta explica como interpretar outro modelo e realizá-lo manualmente no Vulcan. Contém somente documentação: sem tradutor, gerador de código, leitor de modelos, biblioteca adaptadora ou motor de migração. `vendor/` normalmente guarda código de terceiros copiado para execução/ferramentas; essa organização foi removida. Documentos-fonte imutáveis ficam em `verification/sources/` para proveniência, separados das ferramentas.
