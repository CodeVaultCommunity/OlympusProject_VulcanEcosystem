# Adoption template

[Português](README.pt-br.md)

Use the [minimal ecosystem](../examples/minimal/README.md) as the executable starting point. This checklist is a documentation template, not a generator or a second incomplete executable example.

1. Identify source editions, case IDs, approved/open decisions and hashes.
2. Declare apps, language/profile, public operations, concrete collaborators and resource lifetimes.
3. Create `apps/` and an explicit root registry/entry; choose default and optional modes.
4. Adopt `docs/L1_AtlasSpecifications`, `L2_MinervaBlueprints`, `L3_Vulcan` and `Shared` as appropriate.
5. Implement selected contracts and channels; preserve permission, validation, failure and persistence semantics.
6. Map ADVS scenarios/supports to executable tests and per-file observations to L2.
7. Run the selected checks and record real environment/results/limits. Review changes before refreshing source hashes.
