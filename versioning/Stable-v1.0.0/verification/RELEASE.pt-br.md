# Verificação da release Stable-v1.0.0

Esta edição local estabelece o primeiro contrato estável do Vulcan. Os três
exemplos realizam 31 módulos executáveis/testáveis do Minerva. Passam cinco
testes estruturais, 50 testes funcionais e a auditoria Atlas → Minerva → Vulcan.

A auditoria confirma o payload Atlas sem perda, a identidade byte a byte das
árvores Minerva embutidas e todos os arquivos, símbolos, métodos, hashes e
arestas até o código. Não se afirma publicação remota ou aprovação humana.
