# Fonte L1 do TaskBoard

Esta pasta contém uma instância Atlas Specifications Stable-v1.0.0, documento `ATLAS-VULCAN-TASKBOARD`, revisão `1`. É a fonte didática deste exemplo, reconstruída manualmente do demo Vulcan anterior e da discussão de requisitos. Não há aprovação independente de stakeholders.

O contrato preserva identificadores atribuídos pela aplicação, títulos aparados de 1 a 120 caracteres, conclusão booleana, autorização por recusa padrão e conclusão repetida idempotente. O Task Board publicado pelo Atlas possui outro contrato; não se declara equivalência entre os exemplos.

Consulte a [fonte estruturada](task-board.atlas.json). O blueprint Minerva referencia seus três casos e onze critérios de aceite. Banco, rotas, comandos e outras escolhas concretas são documentados nas responsabilidades de realização e interação.
