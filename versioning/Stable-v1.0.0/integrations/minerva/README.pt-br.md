# Integração com o Minerva

O Vulcan Stable-v1.0.0 consome projetos `minerva-project/1.0.0` cuja autoridade
semântica é `distributed_markdown_modules`. Caminho, símbolo e métodos públicos
descritos no módulo Markdown são normativos. O Vulcan acrescenta código,
composição e evidência sem remover a semântica herdada do Atlas.

Código de ferramenta concreta implementa a linhagem abstrata do Minerva.
Somente adaptadores de interação são Boundaries; testes usam pontos de
observação.
